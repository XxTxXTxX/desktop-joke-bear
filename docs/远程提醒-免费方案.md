# 远程提醒 · 0 成本方案（双方都在国内）

> 结论：**不要自建中继服务器，用私有邮箱当通道。**
> 邮件是免费方案里唯一"不需要服务器、又不会被跨境链路抽风掐断"的选项。

## 1. 拓扑

```
你的手机（任意邮件 App）
      │ 发邮件 → remind-xxxx@qq.com（标题=要提醒的话）
      ▼
邮箱服务器（QQ / 163，国内多线，免费）
      │ IMAP IDLE 长连接（服务器主动推送新邮件）
      ▼
她的电脑 · 桌宠
      ├─ 校验发件人白名单
      ├─ 解析时间规格（at: 20:00 / in:30m / repeat: daily）
      └─ 按本机时钟排进提醒队列 → 熊在气泡里说出来 + 提示音
```

出站连接：她的电脑主动连邮箱的 993 端口，所以 NAT / CGNAT / 动态 IP 全都不影响，
**她的电脑不需要任何公网可达性**。

## 2. 为什么是邮件（对比表）

| 对比项 | 邮件方案 | 免费云函数 / CF Workers | 免费 VPS（Oracle 等） |
|---|---|---|---|
| 国内可达性 | QQ/163 自有骨干，几乎不打折 | workers.dev / vercel.app 经常抽风 | 需外币卡，实例常被回收 |
| 延迟 | IMAP IDLE 推送 1–5 秒 | 跨境 1–3 秒但抖动大 | 看机房 |
| 成本 | 0 | 0 | 0（但注册门槛高） |
| 需要维护 | 无 | 无 | 要开机、要备份、要续期 |
| 域名/备案 | 不需要 | 不需要 | 绑域名进境内要备案 |

## 3. 部署步骤

### 她那边（3 步 / 3 分钟）

1. 建一个**专用**邮箱（建议 QQ 邮箱，微信里能直接看信），在设置里开启
   「IMAP/SMTP 服务」，拿到 16 位**授权码**（不是登录密码）。
2. 桌宠设置面板填三项：邮箱地址、授权码、允许的发件人（你的邮箱）。
3. 完成，之后不用管。

### 你那边（2 步）

1. 把她的提醒邮箱存成联系人（名字随意，比如"她的熊"）。
2. 发信格式：

```
标题：喝水
正文（可选）：
at: 20:00            # 或 in:30m / at:2026-11-20T08:00
repeat: daily        # 或 weekday
urgent: true         # 静音时段也要立刻说
```

不写正文 = 立刻提醒。

## 4. 代码改造点

| 位置 | 改动 | 说明 |
|---|---|---|
| 新增 `bearpet/mailbox.py` | IMAP IDLE 客户端 | 连 993 → IDLE → 有推送就 UID FETCH 新邮件 → 白名单过滤 → Message-ID 去重 → 丢进 `ReminderStore.add_from_remote` |
| `app.py` | 配置 `mail: {host, port, user, secret, allow_from}`；启动时拉起线程；面板显示通道状态 | 授权码用 Windows DPAPI 加密（`CryptProtectData`），不裸存 |
| `remind_ui.py` | 面板显示"邮件通道：已连接 / 重连中 / 未配置" | 复用现有的状态点样式 |
| `relay/` | 原样保留，作为将来的可选通道 | 有服务器时改 `remote.url` 即可，代码不动 |
| `tools/test_mail.py` | 用假 IMAP 响应验证解析/白名单/去重；真实链路单独做一次人工验收 | 见验收标准 |

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 授权码泄露 | 专用邮箱、DPAPI 加密、发件人白名单只放一个人；出事直接重置授权码 |
| QQ 邮箱 IDLE 被踢 | 每 9 分钟 NOOP 保活；掉线后 5 秒退避重连；退化到 30 秒轮询 |
| 她电脑睡眠/关机 | 邮件留在服务器（不自动删），唤醒后补收；迟到 15 分钟以上加「（补一句）」前缀 |
| 邮件被判垃圾/延迟 | 发件地址加入白名单联系人；标题避免"提醒/重要/中奖"等词 |
| 免费额度天花板 | 两人一天几条远低于配额；要"已送达回执/多设备/离线告警"时再上 VPS |

## 6. 里程碑

| 阶段 | 内容 | 工作量 | 验收 |
|---|---|---|---|
| M1 | `mailbox.py` + 配置 + 面板状态 | 1 天 | 发邮件 → 熊说出来 |
| M2 | 时间规格 / 白名单 / 去重 / DPAPI / 重连 | 1 天 | 定时、"明天 8 点"、静音时段都对 |
| M3 | `tools/test_mail.py` + 验收用例 | 0.5 天 | 立刻 / 定时 / 非白名单拒绝 三条断言通过 |
| M4 | 打包 exe + 托盘 + 首次运行向导 | 1–2 天 | 干净 Windows 上双击安装可用 |

## 7. 验收标准（做完必须能过）

1. 你在外面用 **4G 流量**发一封邮件，她屏幕 **5 秒内**出现那只熊说的话。
2. 电脑合盖 2 小时后打开，错过的提醒按时间顺序补出来。
3. 用别人的邮箱发同样内容，熊完全不理会（白名单生效）。
4. 断网 10 分钟再恢复，通道自动重连，期间产生的邮件不丢。
