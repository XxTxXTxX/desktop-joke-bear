# 自定义语音 / 音效目录 (`assets/sounds/`)

把你在 Windows 上录好的 `.wav` 音频文件放到这个目录下，自嘲熊就能在对应时机播放你的录音。
放在 `assets/sounds/` 里的文件会随自动更新（`bootstrap.py`）一起同步下发。

## 推荐音频规格
- **格式**：`.wav`（PCM 16-bit，单声道或双声道均可，Windows 原生 `winsound.PlaySound` 直接异步播放，无延迟）
- **时长**：1 ～ 4 秒最佳，剪掉首尾空白静音段

## 预留文件名约定（放进来即可生效）
- `remind.wav`：定时提醒 / 手机远程提醒弹窗时播放（若未放置则默认使用原来的双音提示音）
- `poke.wav`：左键戳熊一下时播放
- `frustrated.wav`：敲键盘太频繁切换为抓狂表情时播放
- `eat.wav`：投喂吃东西 / 喝咖啡 / 吃汉堡时播放
- `parkour.wav`：桌面跑酷跳上窗口顶沿时播放
